Alta API Documentation

Alta APIs can be found at https://manage.alta.inc/api/...
For example, "POST /account/forgot" would be accessible at https://manage.alta.inc/api/account/forgot
Nearly all APIs are JSON-encoded (in and out).
Most APIs will respond {} for success, and HTTP code 400 for an error.

Email/password authentication is performed using AWS Cognito. An example of how
to obtain a token (ID token) with node.js is below:

import { CognitoUserPool, CognitoUser, AuthenticationDetails } from
  'amazon-cognito-identity-js';

const UserPoolId = 'us-east-1_4QbA7N3Uy';
const ClientId = '24bk8l088t5bf31nuceoqb503q';

let Username = "user@email.com";
let Password = "mypassword";

const getToken = async () => {
  const userPool = getUserPool();
  const cognitoUser = getCognitoUser(userPool);
  const authenticationDetails = getAuthenticationDetails();

  return new Promise((resolve) => {
    cognitoUser.authenticateUser(authenticationDetails, {
      onSuccess: function (result) {
        const token = result.getIdToken().getJwtToken();
        resolve(token);
      },
      onFailure: function (err) {
        console.log('error is ', JSON.stringify(err));
        resolve(null);
      }
    });
  });
};

const getUserPool = () => {
  const poolData = {
    UserPoolId: UserPoolId,
    ClientId: ClientId // Your App client id here
  };
  const userPool = new CognitoUserPool(poolData);
  return userPool;
};

const getCognitoUser = userPool => {
  const userParams = {
    Pool: userPool,
    Username: Username
  };
  const cognitoUser = new CognitoUser(userParams);
  return cognitoUser;
};

const getAuthenticationDetails = () => {
  const authenticationData = {
    Username: Username,
    Password: Password
  };
  const authenticationDetails = new AuthenticationDetails(authenticationData);
  return authenticationDetails;
};

const main = async () => {
  const token = await getToken();
  console.log(token);
};

main();

Endpoints that do not require a JWT

POST /account/confirm-forgot

Confirm code and change Cognito user password

  • body.email: Email account to request code for (required)
  • body.code: One-time code to change password
  • body.password: New password (required)

POST /account/forgot

Initiate resetting of Cognito password by sending one-time code to email

  • body.email: Email account to to request for (required)

POST /account/login

Log into an account (local controller only)

  • body.email: Account email (required)
  • body.password: Account password (required)
  • Returns { token: JWT, name: Account Display name }

POST /account/login-passkey-start

Start Cognito passkey login

  • body.email: Account email (required)

Returns Cognito challenge data for WEB_AUTHN

POST /account/login-passkey-complete

Complete Cognito passkey login

  • body.email: Account email (required)
  • body.session: Cognito session from login-passkey-start
  • body.credential: AuthenticationResponseJSON credential from WebAuthn (required)

POST /account/login-google

Log in with Google Oauth (Deprecated for AWS Cognito)

  • body.gtoken: Token from google (required)
  • Returns { token: Our JWT, name: Account Display name, picture: Account avatar }

POST /account/new

Create new account, inserts token into db that must be verified later.
NOTE: This will only be used for a local controller.

  • body.name: Name on account (required)
  • body.email: Email account to create (required)
  • body.password: Password for new account (required)
  • body.gtoken: Recaptcha token

POST /account/recover

Start account recovery process by inserting new token into db, and emailing it

  • body.email: Account email (required)

POST /account/signup

Sign up for Cognito account

  • body.email: Email account to create (required)
  • body.password: Password for new account (required)
  • body.name: Name (required)

POST /account/verify

Verify an account token to finalize account creation

  • body.token: Previously sent token to authorize request + space + account email (required)
  • body.passwd: Optional new account password (required)
  • body.nopasswd: True if the token should stay in the db for further verification
    like account recovery
  • Returns { noPasswd: true } if there was no password supplied for verification

GET /account/verify

Verify an account token to finalize account creation

  • body.token: Previously sent token to authorize request + space + account email (required)
  • body.passwd: Optional new account password (required)
  • body.nopasswd: True if the token should stay in the db for further verification
    like account recovery
  • Returns { noPasswd: true } if there was no password supplied for verification

POST /device/boot

Record device boot event. Also stores IP addresses for device set up

  • body.id: Device ID (MAC address) (required)
  • body.pubkey: Device Public key (required)
  • body.version: Device FW version (required)
  • body.model: Device model (required)

POST /device/cert

Set up a DDNS pointer (e.g. from 192-168-x-x.$ddnsid.ddns.$DOMAIN to IP)

  • body.mid: Device MID (required)
  • body.ip: IP address to configure (i.e. 192.168.1.5) (required)
  • body.ip6: IPv6 address to configure
  • body.ip6ll: IPv6 LL address to configure
  • body.pubip: Public IPv4 address to configure for public.$ddnsid
  • body.pubip6: Public IPv6 address to configure for public.$ddnsid
  • body.auth: Auth string to give to LetsEncrypt to prove domain ownership
  • body.replace: Replace all ddns entries for this MID

POST /device/state

Record IPv4 VLAN addresses this device has observed in use, and
optionally its complete advertised-BSSID set. Existing VLAN address
rows are retained; freshness determines which one DNS considers current.

  • body.mid: Device MID (required)
  • body.vlanAddresses: Array of observed { vlan, ip } pairs (batch form)
  • body.bssids: Array of compact or colon-delimited BSSIDs (optional)

POST /device/event

Upload a device event, like an IPS alert

  • body.type: ips (required)
  • body.mid: Device MID (required)
  • body.id: Event ID (required)
  • body.data: Event data (required)

POST /device/local-cert

Set up a DDNS pointer for a locally-hosted device
(e.g. from 192-168-x-x.$ddnsiddev.$ddnsidcontroller.$DOMAIN to IP)

  • body.mid: Local Controller MID (required)
  • body.ddns: Same ddns object as POST /device/cert
  • body.replace: Replace all ddns entries for this Controller MID+Device MID combo

POST /device/local-state

Record network presence for a device hosted by a local controller.

POST /device/detected

Notify of detected device; similar to /device/boot except that the device
was detected by an already-configured device.

  • body.mid: Detector mid (required)
  • body.id: Detected Device ID (MAC address) (required)
  • body.pubkey: Detected Device Public key (required)
  • (mesh add only) body.model: Detected Device Model
  • (mesh add only) body.version: Detected Device Model
  • Returns: Key that detector can send to detectee to allow addition into site

POST /device/link

Store current LLDP neighbor, for use when/if the device ever goes disconnected

  • body.descr: LLDP peer description/firmware
  • body.mac: LLDP Peer MAC address
  • body.mid: Managed device MID (required)
  • body.name: LLDP peer name
  • body.p: Device's local port number (required)
  • body.port: LLDP peer port description

POST /device/oops

Upload a userland or kernel crash

  • body.type: user or kernel (required)
  • body.deviceid: Device ID (required)
  • body.sig: Signature - sha256(req.dmesg (or req.dump)+req.deviceid+salt) (required)
  • body.{cmdline,comm,maps,dmesg,status}: Userland crash info
  • body.date: Unix Epoch time of crash
  • body.count: Block number (for dumps only)
  • body.bs: Block-size

POST /device/release

  • body.releaseToken: release token (from /device/grab email) (required)

POST /push

MID, recipient email addresses, and notification content.

POST /fe/oops

POST /device/backup

Download a versioned backup containing the complete device database row.
A DDNS token is included when available so a restore can prove ownership
of, and reuse, the backed-up DDNSID.

  • body.id: Device ID (required)

POST /device/restore

Restore configurable fields from a versioned device backup. The target
device retains its physical identity, site, keys, runtime state, and MID.
The device-level DDNSID is reused only when its token is valid; otherwise
a new ID is assigned. A locally hosted device's full DDNS hostname also
contains its controller DDNSID, which is intentionally not restored here.
Any other device displaced within the target controller namespace receives
and is synchronized with its own new DDNSID.

  • body.id: Target device ID (required)
  • body.backup: Parsed device backup object (required)
  • body.skipDdnsRestore: Keep the target device's current DDNSID (optional)

POST /device/edit

Update a device's name or other settings

  • body.id: Device ID (id or ids required)
  • body.ids: Array of Device IDs (id or ids required)
  • body.name: Device Display Name
  • body.chan2: 2 GHz channel
  • body.width2: 2 GHz channel width
  • body.txp2: 2 GHz TX Power (auto, high, medium, or low)
  • body.colors: Array of colors (e.g. ['black', 'blue'])
  • body.chan5: 5 GHz channel
  • body.width5: 5 GHz channel width
  • body.chan6: 6 GHz channel
  • body.width6: 6 GHz channel width
  • body.txp5: 5 GHz TX Power (auto, high, medium, or low)
  • body.txp6: 6 GHz TX Power (auto, high, medium, or low)
  • body.network: Network protocol (dhcp or static)
  • body.lanip: Static IP address
  • body.subnet: Static IP Subnet
  • body.dns1: DNS Server #1
  • body.dns2: DNS Server #2
  • body.vlan: Management VLAN
  • body.fallback: true/false to enable network fallback
  • body.alwaysOn: true/false to keep broadcasting even when Internet is down
  • body.leds: null (follow site settings), 'blue', 'white', 'off', or
    hex '#rrggbb' for switches
  • body.linkLeds: null (follow site settings), 'enable', 'noblink', 'disable'
  • body.mesh: true/false to enable/disable wireless mesh, null to use
    firmware default (enabled), or a 12-hex-digit physical AP MAC to prefer as uplink
  • body.igmpSnooping: Array of VLAN IDs with IGMP snooping. Only on APs with switches
  • body.poePassthru: true/false to enable POE passthrough on the output port
  • body.nodoh: true to disable DOH
  • body.portsCfg: Switch port configuration
    • portsCfg.ports: Object of switch port configuration objects:
      • Key: Port number, 0 = Port #1, for example: { portsCfg: { 0: { name: ... } } }
      • name: Port name (default blank)
      • mode: ''/undefined: Standard (default), 'disable': Disabled, '8021x': 802.1x,
        mirror:Number: Mirror another port,
        :combine:A,B,C: LACP with other ports
      • vlan: Native VLAN (Number). undefined: Use port-color setting.
      • allowedVlans: Allowed VLANs object. undefined: User port-color settings.
        • all (Boolean): If true, then all site-wide VLANs will be allowed on this port
        • list (Number Array): List of allowed VLANs
      • poe: Enable POE. undefined: Use port-color setting.
        'on': Enable, 'off': Disable
      • speed: Speed configuration. undefined: Use port-color setting.
        'auto'/undefined (Auto-negotiate) (default), '1000' (1000 Mbps FDX),
        '100f' (100 Mbps FDX), '100h' (100 Mbps HDX), '10f' (10 Mbps FDX),
        '10h' (10 Mbps HDX)
      • isolation: Port isolation. undefined: Use port-color setting.
        'on': Enable, 'off': Disable
      • dlRate: Download rate (Float, in Mbps). undefined: Use port-color setting.
      • ulRate: Upload rate (Float, in Mbps). undefined: Use port-color setting.
      • voiceVlan: Voice VLAN (Number). undefined: Use port-color setting.
      • stp: Enable loop detection. undefined: Use port-color setting.
        'on': Enable, 'off': Disable
      • allowed: Allowed MACs (String). undefined: Use port-color setting.
        'list': Use allowedList setting on this port.
      • allowedList: Allowed MACs (String). undefined: Use port-color setting.
        New-line delimited list of allowed MAC addresses.
      • qosMode: QoS behavior for this port. undefined/'default': Use port-color QoS,
        'custom': Use this port's own qos object, 'disabled': Disable QoS on this port.
      • qos: Optional per-port QoS object, used when qosMode is 'custom':
        • profile: "default" | "dante" | "crestron" | "qsys" | "shure" | "aes67" | "enterprise" | "voip"
        • basePriority: Base switch priority, 0-7
        • rules: Array of override rule objects:
          • id: Unique rule ID
          • map: Array of DSCP/TOS mapping objects:
            • type: Optional. Default is 'dscp'; use 'tos' for TOS / IPv6 traffic class matching.
            • value: DSCP (0-63) or TOS / IPv6 traffic class (0-255) value,
              or an array of such values that share the same priority handling
            • mode: Optional. Default is 'offset'; use 'absolute' for a static priority
            • prio: Switch priority (0-7), or amount to add to basePriority
      • schedule: Schedule profile ID. Switches and routers only.
    • portsCfg.aggregations: Array of router port aggregation objects:
      • ports: Zero-based numeric port indexes included in the aggregation. Linux
        interface names are generated by the backend for firmware config.
      • masterPort: Zero-based numeric port index whose portsCfg.ports settings
        own the aggregation. Other member port settings are ignored.
      • mode: '802.3ad' for LACP, or 'active-backup' for active-passive.
        LACP is only used when all member ports support the same speed group;
        otherwise active-backup is used.
      • ifName: Optional firmware bond interface name. If unset or duplicated,
        the backend generates a unique bond name.
  • body.radius: RADIUS server ID, for Switch port auth.
  • body.services: Services object
    • radius: RADIUS Server config object
      • enabled: true or false
      • authPort: RADIUS authentication port (default 1812)
      • acctPort: RADIUS accounting port (default 1813)
      • secret: RADIUS shared secret (auto-generated by FE)
      • interimUpdate: Interim Update Interval (default 3600 seconds)
      • tunneled: True to enable tunneled reply (default enabled)
      • users: Array of RADIUS user objects []
        • id: Unique ID for this user
        • username: RADIUS username
        • password: RADIUS password
        • vlan: WiFi VLAN to assign to this user
        • wifiIp: Static IP address to assign user on WiFi (Framed-IP-Address)
        • vpnIp: Static IP address to assign to this user on VPN
    • vpn: Array of VPN Server config objects []
      • type: 'ipsec', 'openvpn', or 'wireguard'
      • enabled: true or false
      • mode: 'l2tp' or 'ikev2' for ipsec
      • psk: l2tp/ikev2: Pre-shared key, wireguard: Private key (string)
      • pubkey: wireguard: Public key (string)
      • subnet: VPN subnet, i.e. 192.168.3.1/24
      • dns: l2tp/ikev2/openvpn: DNS servers array, default auto (string)
      • wins: l2tp/ikev2: WINS server (string)
      • compatible: l2tp/ikev2: Allow weak ciphers and disable strong auth, for compatibility
  • stp: Enable STP (Routers only, default true)
  • body.stpPriority: Switch STP bridge priority
  • body.location: device location to display in snmp

  • body.siteid: SiteID (required)

POST /filter

Update site filter settings

  • body.siteid: SiteID (required)
  • body.domains: NL-delimited list of strings
  • body.blockedApps.list: Array of strings, e.g. ["netflix","disneyplus"]
    not including groups such as Chat or Gaming. The application should
    expand the groups into the applications under it before sending this
    value. The APs do not have a mapping of groups to applications, so the
    web front-end/mobile app should expand this.
  • body.blockedApps.selections: Array of strings, e.g. ["netflix","disneyplus"]
    including selected groups.
  • body.blockedRegions: Array of country codes to block, e.g. ["IR", "KP"]
  • body.blockedLists: Array of block lists, e.g. ["bogon", "firehol1"]

POST /site

Updates site's settings

  • body.id: siteid (required)
  • body.backnet: Backup network, e.g. 10.188.0.0/16. Blank to disable backup network.
  • body.disconnectTimeout: Time to wait before sending disconnected device notification. Empty
    to use default of 120 seconds.
  • body.dpiEngine: Enable/disable DPI engine on APs
  • body.routerDpi: Enable/disable DPI engine on Routers
  • body.emails: Update emails
  • body.ips: IPS config: { enabled: true/false, notifyLevel: 1, 2, or 3,
    blockLevel: 1, 2, or 3, vlans: [ 1, 2, 3] (all if blank/unset) }
  • body.stpMode: Set switch STP mode to MSTP/RSTP/STP
  • body.ddm: Capture/display SFP DDM information
  • body.leds: One of "white", "blue", or "off"
  • body.logAPs: MB to reserve for persistent AP logs. Null uses ephemeral logs.
  • body.logRouters: MB to reserve for persistent Router logs. Null uses ephemeral logs.
  • body.logSwitches: MB to reserve for persistent Switch logs. Null uses ephemeral logs.
  • body.hotspotEmailHourlyLimit: Maximum captive-portal verification emails
    sent from this site during any rolling hour. Null uses the default of 100.
  • body.noInvite: Do not send invite email if there are new users to the site
  • body.portColors: Object of port color configurations; see /device/edit portsCfg settings.
    For example: { portColors: { blue: { vlan: 2 ... } } }
    Black color has the following defaults, which cannot be modified:
    { vlan: 1, allowedVlans: { all: true }, speed: 'auto', isolation: 'off', dlRate: 'none',
    ulRate: 'none', lldpMed: 'on', voiceVlan: undefined (none), loopDetection: 'on',
    stormControl: {}, allowedMacs: undefined (any) }
    Port colors can also define qos with the same shape as /device/edit portsCfg.ports[*].qos
    and act as the inherited default for ports using qosMode = 'default'.
  • body.radii: Radius server array, e.g. [ {
    id: 'id', name: 'name', authIP: '192.168.1.1', authPort: 1812, acctIP: '192.168.1.1', acctPort: 1813
    } ]
  • body.sshKeys: Array of ssh public ssh keys
  • body.dns: Site DNS settings (defaultTTL, useDoH, forceDoH, dohServers, dohBootstrapServers,
    allServers, logQueries, records). DoH servers are comma-separated HTTPS URLs;
    bootstrap servers are comma-separated IPv4/IPv6 addresses. Blank uses firmware defaults.
    Record type defaults to A and is omitted for A records; omit TTL when it matches the site default (300).
    DNS hostnames MUST be lowercase: every record.name and hostname fields in record.value
    (CNAME/NS/PTR target, MX exchange, SRV target, SOA names, NAPTR replacement).
    Preserve case in TXT text, NAPTR flags/services/regex, and DoH URL paths/query strings.
  • body.routes: Array of Static Routes,
    i.e.: [ { id: '1234', name: 'ToOffice', network: '192.168.2.0/24', nextHop: '192.168.1.1' } ]
  • body.profiles: Array of connection profiles,
    i.e.: [ { id: '1234', name: 'test', "type":"iot","vlan":4,"dlRate":50,"ulRate":5,"maxClients":2 } ]
  • body.switchLeds: One of "white", "blue", "off", or hex "#rrggbb"
  • body.syslogHost: Remote syslog host, e.g. 192.168.1.1 or 192.168.1.1:514
  • body.tz: Time zone
  • body.update: Automatically update firmware
  • body.updateWindow: null for default, or 0-1439 for minutes after midnight in the site timezone
    when the 1-hour auto-update window starts
  • body.updateDays: null for default, bitmap of days of the week where updates are allowed, 0 being Sunday
  • body.useArpReq: Use ARP requests to learn wired device IP addresses, in addition to responses
  • body.vlans: Array of VLAN definitions, i.e.: [ { id: 1, notes: "Main VLAN", igmpSnooping: true } ]
  • body.wans: Array of WAN definitions, i.e.: [ { id: 'default1', name: 'WAN1', type: 'dhcp' } ]
  • body.firewall: Firewall definition, i.e. { firewall: { rules: [{ id: ... }] }, nat: [] }
  • body.notifications: Object of notification config,
    i.e. { "user@email.com": { "discon": true, "access": true } }
  • body.perms: Object of permissions config,
    i.e. { "user@email.com": { "admin": true, "allPasswords": true, "unlockedPasswords": true } }
  • body.community: snmp community string
  • body.username: snmpv3 username
  • body.password: snmpv3 password
  • body.contact: snmp contact field
  • body.autoDfs: allows auto channel selection to select DFS channels
  • body.autoNonPsc: allows auto channel selection to select non PSC channels
  • body.rchans2: array of channels restricted from 2GHz auto channel selection
  • body.rchans5: array of channels restricted from 5GHz auto channel selection
  • body.rchans6: array of channels restricted from 6GHz auto channel selection
  • body.dhcpGuard: 'auto', 'manual', 'auto + manual', or 'disabled'
  • body.dhcpMacList: List of MAC addresses that are allowed to provide DHCP responses
  • body.txName: Transmit AP name within beacon
  • body.webhook: Webhook URL to call when device disconnections are detected. Uses POST method with Content-Type of "application/json".
  • body.width2: 2 GHz default bandwidth. 0 = automatic
  • body.width5: 5 GHz default bandwidth. 0 = automatic
  • body.width6: 6 GHz default bandwidth. 0 = automatic
  • body.pbrRules: Array of policy-based routing rules
  • body.location: Site location, e.g. { lat: 37.169, lng: -113.417 }
  • body.apRgbLeds: One of "white", "blue", "off", or hex "#rrggbb"
  • body.dashboard: Dashboard config, e.g. { enableSiteLocation: false }
  • body.ipMonitorTimeout: timeout in seconds before monitored device is rebooted.

POST /wifi/ssid

Update/Add WiFi SSID config

body.config is ultimately passed directly to APs, including password
config/definition, etc.
Defaults below are what the Front-end should use to initialize a new
SSID with.

  • NOTE: Field types may change at any time. Parsers should assume that
    number-like values could potentially be passed as strings or integers,
    and booleans could potentially be 0 or 1, etc. If a parser is unable
    to handle a specific value, Alta Labs (and/or the developer) should
    immediately be alerted to avoid poor user experience (i.e. this
    should be treated as a "crash")
  • body.config (set field to null to delete from config):
    • ssid (String, required): SSID, i.e. WiFi Network Name
    • sites (String Array, required): Site IDs to broadcast SSID on
    • id (String, required): Set to "new" if creating new SSID
    • acl (String): "off" to disable ACL, "allow-list" to only allow MACs
      on the aclList, "deny-list" to deny MACs on the aclList, default "off"
    • aclList (String): Newline-delimited list of MAC addresses to block or allow
    • bands (String): "both" for 2 and 5 GHz, "5" for 5 GHz, "2" for 2 GHz,
      default "both"
    • colors (String array): Color groups that this SSID belongs to. APs
      that match the colors here will broadcast this SSID. Default ["black"]
    • dlRate (Number): Download limit, in Kbps. Default is to not specify.
    • dtim2 (Number): WiFi DTIM setting on 2 GHz band, default 1
    • dtim5 (Number): WiFi DTIM setting on 5 GHz band, default 3
    • enabled (Bool): Disables SSID if false, set to null to use default of
      enabled
    • fastRoaming (Bool): Enable/disable 802.11r
    • hidden (Bool): Enable/disable broadcasting of SSID publicly
    • hotspot (Bool): Enable/disable WiFi hotspot
    • hotspotExt (String): (External hotspot only) External hotspot URL
    • hotspotExtAuth (String): (External hotspot only) Newline-delimited
      list of IPs and hostnames that are allowed to be reached by guests
      prior to authorization
    • hotspotFinish (String): URL to redirect authorized hotspot users to
      after authorization is complete
    • hotspotCollectEmails (Bool): Require local-hotspot guests to submit
      and verify an email address
    • hotspotEmailRateLimit (Bool): Limit guest upload and download speeds
      until their collected email address is verified. Defaults to true.
    • hotspotEmailDlRate (Number): Pre-verification download limit, in
      Kbps. Defaults to 1000 (1 Mbps); 0 disables this directional limit.
    • hotspotEmailUlRate (Number): Pre-verification upload limit, in Kbps.
      Defaults to 1000 (1 Mbps); 0 disables this directional limit.
    • hotspotEmailRatesLinked (Bool): Whether the admin UI keeps the
      pre-verification upload and download limits equal. Defaults to true.
    • hotspotEmailOptInRequired (Bool): Require the promotional-email
      checkbox before accepting an address. Defaults to false.
    • hotspotEmailOptInText (String): Text displayed beside the
      promotional-email checkbox.
    • hotspotEmailPrivacyPolicy (String): Full privacy policy displayed
      in the captive portal. Maximum 10,000 characters.
    • hotspotTimeout (Int): Guest connection and email-verification
      lifetime in seconds. Defaults to 4 hours.
    • hotspotLogo (String): (Local hotspot only) hotspotLogo ID obtained
      from /wifi/ssid-blob
    • hotspotPassword (String): (Local hotspot only) Password required to
      authorize hotspot guest
    • hotspotSecret (String): (External hotspot only) Secret used to
      authorize external hotspot portal authorization request
    • hotspotTerms (String): (Local hotspot only) Hotspot Terms of Service
    • hotspotTermsTitle (String): (Local hotspot only) Hotspot Terms Title
    • hotspotTitle (String): (Local hotspot only) Hotspot Title
    • hotspotType (String): "local" or "external"
    • igmp (Bool): Enable IGMP/Multicast Snooping
    • merge: Merge this config with existing SSID config, instead of
      replacing completely. Useful for updating only a few fields.
    • minrate2 (Number): Minimum WiFi data rate, in Kbps. Valid values:
      1000, 2000, 5500, 6000, 9000, 11000, 12000, 18000, 24000, 36000,
      48000, 54000. If not set (which should be the default), AP will
      use firmware-defined default.
    • minrate5 (Number): See minrate2, but for 5 GHz. Valid values:
      6000, 9000, 12000, 18000, 24000, 36000, 48000, 54000.
    • network (Number/String): "main" for native VLAN1, or VLAN ID number,
      default "main"
    • notes (String): Notes to attach to this SSID
    • passwords (Password Array): See Password definition below
    • vouchers (Voucher Array): Same as password definition with added fields for duration and single use
    • pmf: (Bool): Enable WiFi PMF (Protected Management Frames)
    • radiusAcctPort (Number): RADIUS Accounting Port Number, default 1813
    • radiusAuthPort (Number): RADIUS Authentication Port Number, default 1812
    • schedule (String): "turn on": Enable WiFi during blocks,
      "turn off": Disable WiFi during blocks
    • scheduleRequest (Bool): Allow user to request time during down time
    • scheduleBlocks (ScheduleBlock Array): See ScheduleBlock definition below
    • security (String): Security type, "password", "enterprise", or "open"
    • template (String): Merge config with pre-defined template (blank or "xnet")
    • type (String): Default type of network filtering, "main", "large",
      "iot", "guest", "internet"; default "main"
    • ulRate (Number): Upload limit, in Kbps, Default is to not specify.
    • wpa3 (String): "on": WPA3 optional, "required": WPA3 required,
      "off": WPA3 disabled; default "off"
    • minrssi2 (Number): minimum RSSI to allow device to authenticate for 2 GHz
    • minrssi5 (Number): minimum RSSI to allow device to authenticate for 5 GHz
  • Password (to use SSID defaults, just do not set specific fields):
    • password (String, Required): WPA-PSK Passphrase
    • dlRate (Number): Download limit, in Kbps
    • schedule (String Array): schedule IDs
    • ignoreHotspot (Bool): Bypass WiFi Hotspot
    • filter (String Array): Filter IDs
    • type (String): Default type of network filtering, "main", "large",
      "iot", "guest", "internet", unset to use SSID default
    • ulRate (Number): Upload limit, in Kbps
    • vlan (Number): VLAN ID
  • ScheduleBlock:
    • days (Number Array): Which days to schedule (0=Mon, 6=Sun)
    • start (Float): Time to start schedule, e.g. 14 = 2PM
    • stop (Float): Time to stop schedule, e.g. 18.5 = 6:30PM
  • Returns: { id }
